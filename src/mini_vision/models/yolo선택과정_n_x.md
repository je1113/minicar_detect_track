# YOLOv8 모델 선택 과정: n · s · m · l · x (AMR 데이터셋)

작성일: 2026-10-02 · 데이터셋: `dataset_amr_v1` (클래스: car, dummy) · 위치: `/home/mu-02/yolotrain_amr/`

AMR 데이터셋으로 YOLOv8의 5가지 크기(n, s, m, l, x)를 **같은 설정, 같은 PC(RTX 4070 Laptop)** 에서 학습해 수업 자료(Day2)의 "KEY METRICS TO COLLECT" 9개 지표를 비교하고, 그 결과로 모델을 선정했다.

## 결론

- **확정: GPU에서 실행하기로 해서 `yolov8s`로 확정한다.** GPU에서는 5개 모델 모두 이미지 1장에 32ms 이하(x 31.7ms)라 속도가 선정 기준이 되지 못하고, 남는 기준인 오류 개수에서 s가 가장 적다(m과 같지만 s가 GPU에서 약 2.7배 빠르고 모델이 작다).
- **선정: `yolov8s`.** conf 0.8과 0.25 두 조건에서 오류가 가장 적고(valid+test 54개 정답 중 conf 0.8에서 오류 0), CPU 98ms / GPU 4.6ms로 속도도 쓸 만하다.
- **단, 검출을 CPU에서 10Hz(프레임당 100ms)로 돌려야 한다면 `yolov8n`이 안전하다.** s는 CPU에서 중앙값 97.6ms로 100ms 한계에 거의 닿는다(상위 10%는 101.5ms).
- **큰 모델(m, l, x)은 이 데이터에서 이득이 없다.** mAP50은 모두 같고, mAP50-95는 오히려 낮거나 비슷하며, CPU 속도가 249~787ms로 크게 느리다.

## 4. 지표 정의

- **5) P/R, 6) F1:** 클래스 평균 F1이 최대가 되는 confidence에서 측정했다.
- **7) % Correct Predictions:** (맞은 예측) ÷ (전체 예측). 클래스가 같고 IoU 0.5 이상이면 정답으로 쳤다. 검출에는 TN이 없어서 정확도 대신 이 방식을 썼다.
- **8) 속도:** 배치 1, test 이미지 15장. **5개 모델을 순서를 돌려가며 5라운드 번갈아 측정한 중앙값**이다. 전처리·후처리를 포함하며, 추론만의 시간은 GPU 2.5 / 3.6 / 11.7 / 18.4 / 30.7ms, CPU 32.8 / 96.4 / 247.5 / 499.8 / 786.3ms (n / s / m / l / x 순)다.
- **9) 평균 신뢰도:** conf 0.25 이상 예측만 집계했다.
- 라벨이 polygon이라 정답 박스는 polygon의 외접 박스로 계산했다(Ultralytics의 학습·검증 방식과 같다).

## 5. 오류 상세: 두 가지 임계값에서의 비교

valid 31장 + test 15장 = 46장, 정답 박스 54개(valid 39 + test 15)를 모두 평가했다. 표의 숫자는 TP / FP / FN이다.

| 모델 | conf **0.25** (오탐 FP) | conf **0.8** | 비고 |
|---|---|---|---|
| yolov8n | 54 / 1 / 0 | 50 / 1 / 4 | 오탐이 신뢰도 0.82로 높음. 0.8에서 정답 4개를 놓침 |
| **yolov8s** | 54 / 1 / 0 | **54 / 0 / 0** | 오탐 신뢰도 0.29로 낮아 임계값으로 걸러짐 |
| yolov8m | 54 / 1 / 0 | **54 / 0 / 0** | 오탐 신뢰도 0.55 |
| yolov8l | 54 / 3 / 0 | 37 / 0 / **17** | 신뢰도가 전반적으로 낮아 0.8에서 정답 17개를 놓침 |
| yolov8x | **54 / 0 / 0** | 52 / 0 / 2 | 0.25에서는 오류 없음 |

conf 0.25에서의 오탐 내용은 다음과 같다.
- **n:** valid `amr_dummy_img_38`의 dummy (신뢰도 0.82)
- **s:** test `amr_car_img_15`의 car (0.29). 화면 오른쪽 사람의 붉은 밑창 신발이며, 이 이미지에서 이전에 yolo26도 같은 오탐을 냈다.
- **m:** valid `amr_car_img_59`의 car (0.55)
- **l:** test `amr_car_img_15`의 car (0.30), valid `amr_car_img_98`의 car (0.27), valid `amr_dummy_img_23`의 dummy (0.33)
- **x:** 없음

## 6. 선정 과정

1. **정확도 지표로는 구분이 안 된다.** mAP50이 5개 모두 0.995이고(valid가 31장뿐이라 상한에 붙어 있음), Recall은 0.984~1.000, 최대 F1은 0.991~1.000으로 차이가 작다. 그래서 **오류 개수와 속도**로 판단했다.
2. **`yolov8l` 탈락.** 50 epoch에서 조기 종료(best 30)됐고, mAP50-95가 0.879로 가장 낮다. 신뢰도가 전반적으로 낮아 conf 0.8에서 정답 54개 중 17개를 놓쳤고, conf 0.25에서도 오탐이 3개로 가장 많다. 원인은 확인하지 못했다.
3. **큰 모델은 이득이 없다.** `yolov8m`, `yolov8x`는 정확도가 작은 모델과 같은 수준인데, CPU 속도가 249ms, 787ms로 매우 느리고 학습 시간과 모델 크기도 크다. mAP50-95 역시 n(0.9335)이 m(0.9273), x(0.9120)보다 높다. x는 batch가 달라 조건도 다르다.
4. **n과 s를 비교한다.**
   - conf 0.8에서 **n은 오류가 5개**(오탐 1, 미탐 4)이고 **s는 0개**다.
   - conf 0.25에서는 둘 다 오탐 1개씩이지만, n의 오탐은 신뢰도가 0.82라 임계값으로 못 거르는 반면 s의 오탐은 0.29라 임계값으로 거를 수 있다.
5. **속도를 확인한다.** s는 GPU 4.6ms로 충분히 빠르고, CPU는 97.6ms다. CPU 10Hz(100ms) 한계에는 거의 닿는다.
6. **결론: `yolov8s` 선정.** 오류가 가장 적고 속도도 쓸 만하다. m도 0.8에서 오류가 없지만 CPU 249ms라 느리다.

### 상황별 선택

| 상황 | 선택 |
|---|---|
| GPU 사용 또는 10Hz보다 느슨한 주기 | **yolov8s** |
| CPU에서 10Hz(100ms)를 반드시 지켜야 함 | **yolov8n** (CPU 33.9ms. 대신 conf 0.8에서는 정답을 일부 놓침) |
| conf 0.25 근처에서 오류 없이 쓰고 싶음 | yolov8x도 가능하지만 CPU 787ms라 현실적이지 않음 |

## 7. 한계와 주의사항

- **표본이 매우 작다.** valid 31장(정답 39개), test 15장(정답 15개)이다. 오류 1~2개 차이로 순위가 바뀔 수 있고, 모델 간 정확도 우열의 근거로는 약하다. 또 valid는 best.pt를 고르는 데 쓰여서 약간 낙관적이다.
- **AMR 검출 노드의 conf 임계값과 추론 장치가 아직 정해지지 않았다.** `amr_detector.py`는 주석뿐인 뼈대다. 그래서 두 임계값(0.25, 0.8)과 CPU/GPU 속도를 모두 보고 조건부로 선정했다. 웹캠 검출 노드(`webcam_detector.py`)가 쓰는 값(CPU, conf 0.8, 10Hz)을 참고용으로 conf 0.8 평가에 썼다.
- **`yolov8x`는 batch가 8이다.** 다른 모델과 완전히 같은 조건이 아니다.
- **`yolov8l`의 낮은 성능 원인은 확인하지 못했다.** 소규모 데이터에서 큰 모델의 학습이 불안정했을 가능성이 있다는 추정일 뿐이다.
- **이 데이터셋은 학습 이미지 318장 중 317장만 쓰였다.** `amr_dummy_img_33...` 1장이 라벨에 polygon과 박스 행이 섞여 있어 Ultralytics가 제외했다. 라벨이 거의 전부 polygon 형식이라 박스로 자동 변환해서 학습했다.
- **v1 데이터(`dataset_amr_v1`)로 학습한 결과다.** v2(`dataset_amr`, train 530장)로 한 학습 결과는 지웠고, 두 데이터의 결과는 직접 비교할 수 없다.
- **속도는 이 PC 기준이다.** 실제 로봇이나 다른 컴퓨터에서는 달라질 수 있다.
- **라벨이 있는 평가 이미지가 부족하다.** 실제 AMR 카메라로 새로 찍은 사진으로 최종 확인하는 것을 권한다.
